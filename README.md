# BUYA-NTASHI FARMS 🌱

**Rooted in Agriculture**

## About the Project
Buya-Ntashi Farms is an urban farming initiative focused on promoting sustainable agriculture through potato farming and fish farming.

The project aims to contribute to food security, employment creation, income generation and economic development.

## Project Objectives
- Promote sustainable farming practices.
- Encourage potato and fish production.
- Support food security.
- Create employment opportunities.
- Promote agricultural knowledge and skills.

## Website Features
